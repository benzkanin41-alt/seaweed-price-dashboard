Source & Methodology

Source: Korea Customs Service Trade Statistics, tradedata.go.kr; workbook extract:
Filter: HS Code 121221, Country Thailand, Item “Fit for human consumption”. ราคา $/Ton = Export Value (USD 000) x 1,000 / Export Weight (Ton).
Aggregation: รายไตรมาส/รายปีใช้ weighted average จาก monthly export value และ export weight. ปีล่าสุดเป็น YTD ตามเดือนล่าสุดในไฟล์ เพื่อหลีกเลี่ยง duplicate 2025 ใน yearly sheet. Trade balance normalize จาก export value - import value.
Growth: รายเดือนแสดง MoM และ YoY เท่านั้น; รายไตรมาสแสดง QoQ และ YoY เท่านั้น; รายปีแสดง YoY เท่านั้น. สำหรับปี YTD ใช้เดือนเดียวกันของปีก่อนเป็นฐานเทียบ.
